Early test version. Free basic demo. No false promises.

Limits notice: Experimental. This does not stop screenshots, screen recording, or anyone who can access the image data directly. It is not legal protection. It only makes some casual and simple automated copying more difficult and can leave a visible mark on the canvas.

What this early test version does

  • Draws a simple protected view only to a canvas (no normal image file on the page).
  • Shows a short visible code on the canvas when unlocked (demo only — the code is not saved or linked to anything yet).
  • Requires a local demo token in this tab before drawing the view.
  • Blocks the right-click menu on the canvas.

The basic version is free to try. It collects nothing. No data is sent anywhere.

For independent creators

The aim of the free basic version is to give people who cannot afford expensive tools a simple way to make casual copying a bit harder and to leave a visible mark they can refer to if a copy appears elsewhere.

Feedback is welcome. This is an early test, not a finished product.
