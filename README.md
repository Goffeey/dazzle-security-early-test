# Dazzle Security — Early test version

**Free basic demo. Experimental.**

## Short description
Make casual and automated copying harder.  
Help keep a better record if it still happens.

Why not give it a try? The basic version is free.

This early test draws a simple view only to a canvas and can show a visible code. It does not stop screenshots, screen recording, or direct access to image data. It is not legal protection.

## Limits
- Does not stop screenshots or screen recording.
- The visible code is not saved or linked to a visitor, time, or page.
- The token is local to the browser tab only.
- Not a finished product. Feedback welcome.

## Privacy
This demo collects nothing. No data is sent anywhere.

## How to try
Open index.html in a browser. Click “Get demo token”, then “Unlock canvas view”.
